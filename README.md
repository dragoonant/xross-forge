# XROSS FORGE

An unofficial, non-commercial, fan-made browser version of the Japanese trading card game
**Xross Stars**, played against an AI. Not affiliated with or endorsed by Brave group,
Game & Co. or any talent agency. No official card art, logos or audio are included; see
[NOTICE.md](NOTICE.md).

Status and decisions: [PLAN.md](PLAN.md). Rules as implemented: [docs/rules.md](docs/rules.md).
